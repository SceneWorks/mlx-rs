## Summary

mlx-rs is a Rust binding and high-level wrapper for Apple's MLX machine learning framework, providing neural network primitives (convolution layers, transformer components, activation functions), automatic differentiation utilities, and example applications for running language models (Mistral, Qwen3) and training on MNIST. The repository is organized as a workspace containing the core mlx-rs crate (published as pmetal-mlx-rs), supporting utility crates for language model tokenization (mlx-lm-utils) and model loading (mlx-lm), internal procedural macros (mlx-internal-macros), and runnable examples that demonstrate inference and training workflows on Apple Silicon hardware.
