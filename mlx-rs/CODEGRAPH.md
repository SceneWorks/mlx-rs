## Summary

mlx-rs is a Rust binding and high-level wrapper around Apple's MLX machine learning framework, targeting Metal GPU acceleration on Apple Silicon. The project provides core tensor operations, neural network layers (activations, dropout, normalization), fast primitives (RoPE, layer norm, scaled dot-product attention, custom Metal kernels), loss functions, and example applications including MNIST training and Mistral/Qwen3 LLM inference. It is structured as a multi-crate workspace with a core library (pmetal-mlx-rs), a language model library (mlx-lm), procedural macro helpers, and runnable examples.
