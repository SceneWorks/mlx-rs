## Summary

mlx-rs is a Rust binding and high-level framework for Apple's MLX machine learning framework, targeting Apple Silicon hardware. The project provides neural network primitives (convolutions, transformers, activations), procedural macros for code generation and builder patterns, language model inference utilities (tokenization, chat template rendering, model loading), and example applications demonstrating MNIST training and LLM inference with models like Mistral and Qwen3. It is organized into a core array/ops library (pmetal-mlx-rs), macro crates (mlx-internal-macros, mlx-macros), LLM utilities (mlx-lm-utils, mlx-lm), and runnable examples.
